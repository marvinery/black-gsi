# Black GSI Fibra

Landing page desenvolvida para a campanha de Black Friday do provedor **GSI Fibra Telecom**.

## Tecnologias

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Funcionalidades

- Layout responsivo pensado para mobile e desktop
- Carrossel de banners com suporte a swipe no celular
- Filtro de planos de internet e seleção direta para orçamento
- Formulário integrado com envio direto para o WhatsApp da equipe comercial
- Consulta de viabilidade por bairros e distritos de Araci
- Pop-up promocional adaptativo (vertical no mobile e horizontal no desktop)

## Como rodar o projeto

```bash
# Instalar dependências
npm install

# Rodar ambiente de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
